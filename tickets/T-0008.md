## Objective
Provide alternative views on the same items: Eisenhower matrix, ABCDE prioritization, and Kanban board with HTMX drag-and-drop.

## Context
Enables different perspectives on tasks without fragmenting data into separate lists.

## Acceptance Criteria
- Eisenhower 4-quadrant view based on urgent and important flags.
- ABCDE view ordered by priority field.
- Kanban board with column item limits and status update via HTMX drag.
- Every state change results in an atomic git commit.

## Plan
1. Implement pure lens filtering and ordering in internal/core.
2. Build web templates for Eisenhower, ABCDE, and Kanban views.
3. Implement HTMX drag-and-drop endpoints.
