## Objective
Support repeatable process templates defined in playbooks/, creating a single parent task with subtasks for each step upon instantiation.

## Context
Standardizes repeated procedures (releases, onboarding, travel checklists) without manual subtask entry.

## Acceptance Criteria
- Parse playbook definitions from playbooks/*.md.
- Instantiate playbook as a task with ordered child subtasks.
- Atomic commit containing all generated items.

## Plan
1. Define playbook file schema and core parser.
2. Implement core playbook expansion function.
3. Wire web trigger for playbook instantiation.
