## Objective
Support parent-child hierarchies across four levels (target, project, task, subtask), promote and demote operations, cascading drop with reasons into the not-doing log, and item archiving.

## Context
Enables items to change size as projects evolve. Ensures dropping high-level goals cascades to children while logging rationale.

## Acceptance Criteria
- Promote and demote operations validate parent level constraints.
- Dropping an item cascades to all child items and logs reasons into the not-doing log.
- Done and dropped items can be moved to items/archive/.
- ID resolution remains consistent across active and archived folders.

## Plan
1. Implement core promote/demote and cascade drop operations.
2. Implement not-doing log format and store serialization.
3. Add store archiving and multi-directory resolution.
4. Add web hierarchy navigation and actions.
